# 已有基线的采用质量阀

用于任何对象的几何、装配、纹理、颜色、材质和展示修改。已接受版本仍可能有旧问题；本阀只防止本轮替换带来退步，不宣称整体还原达标。新建无旧基线时按参考与既有阶段契约审查，不虚构前后对照。

## 执行

1. 施工前保存实际基线、输入和恢复地址，列出修改及依赖区域。共享曲面、材质或连接使区域耦合时按组检查。
2. 用同相机、画幅、姿态、模型变换、曝光及灯光捕获基线和候选。灯光本身是修改目标时，另保留固定照明的几何/材质检查，并单独比较实际展示；条件不一致不得冒充严格对照。
3. 实际看图，逐区记录 improved / unchanged / regressed / uncertain 与具体理由；结合参考判断设计忠实度。曲面另查中性轮廓和掠射光，附件另查贴合与多视角；按需选择，不强制每次全量套餐。
4. regressed 不采用；uncertain 保留基线，继续隔离试验或请求必要的设计确认。无退步且结论明确的改动可采用，其他区域保持不变即可。混合结果只在证明依赖独立时局部采用，否则整个相关组保留旧版。
5. 替换默认案例/交付基线之前运行下述记录检查；保留前后图、模型身份及判断。失败候选可保留作诊断，但不能作为默认版本或静默回退来源。技术通过不能覆盖视觉退步；不得改参考、删失败证据或靠总分抵消问题。

## 可重复记录检查

`python3 scripts/adoption_check.py REVIEW.json --out adoption-result.json`

REVIEW 包含 baseline、candidate（各为 path 与 sha256），same_conditions:true，required_regions（本轮受影响及依赖区域ID列表），regions（逐项 id、verdict、reason、before、after；图片同样为 path 与 sha256）。路径相对 REVIEW。只允许一个基线/候选身份；分组采用先生成组内真实最终候选，重新捕获审查。

退出0仅表示记录允许采用；退出1包括 retain-baseline、pending、invalid。脚本验证资源身份、覆盖和判断的一致性，不会自动看图，不验证区域清单是否遗漏，也不自动更改案例或替代现有 project/state 正式认证。执行者必须实际审查并覆盖真实依赖，不能批量填 unchanged。采用动作须先读检查结果；失败时保留旧注册项，明确报告候选未采用。

已存在的 repair-review 等审查继续复用；无需重复填写同一观察，生成该轻量检查记录即可。用户明确要求查看未采用候选时可单独展示，并标注候选身份。
