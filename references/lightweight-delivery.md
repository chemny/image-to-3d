# 轻量展示交付 v1

适用于新建、修复后的新版本和明确迁移的旧项目。不改变既有 project/state 阶段，不新建批准状态。打包通过不是造型、材质或图片还原通过。

## 默认规则

1. 完整几何只通过一个运行入口加载。不得把完整顶点/索引同时嵌入 JS 又供界面通过 JSON 重复下载。
2. 运行代码、压缩几何和界面元数据分离。通用模块使用 `model-data.json.gz`（小数据若 gzip 更大则用 identity JSON）；`model.js` 顶层加载一次并导出 `sceneMetadata`。查看器及功能检查复用模块缓存，不另取完整几何建立菜单。
3. 锁定车辆模板的纯适配器限制保持原样。禁止 fetch/额外 import 的模板使用内嵌 gzip/base64 数据，同样只解码一次；计入 base64 和代码实际体积，不只报 gzip 内部字节。
4. `engineering/spec.json`、`engineering/scene.json` 是制作/重建来源，默认不由展示页加载。完整工程、审查证据和原图保留；不要为减小展示资产删除它们。明确区分展示资产体积和工程历史总磁盘占用。
5. 贴图按源内容 SHA-256 去重，保留每个材质的映射槽、色彩空间、重复倍率、法线倍率及其他参数。相同文件可以共享，材质对象不能因去重发生换色污染。
6. 默认展示资产目标为 **50,000,000 字节**，通过 Spec 的 `delivery_profile.budget_bytes` 覆盖。统计模型数据、专属 JS/页面/配置及材质贴图；公共引擎、参考图、工程源和原生交换文件单独列出。不得把这些排除项说成不存在或已压缩。
7. 先去重复、无损压缩和清理确认未引用的展示资源。不得自动减面、量化、降贴图质量、合并材质或删除隐藏部件。超过预算时报告真实大小和原因，保留质量；有损优化需另定范围和对照方案。
8. 几何体积和运行性能分开记录。gzip 不减少解压后的顶点、三角面或 GPU 内存；不能用压缩比当作帧率提升证据。

## 现有流程中的执行位置

- `project.py build` 默认写入轻量运行资产、制作来源、`delivery-layout.json`、`delivery-size.json` 和包含全部资源的 bundle 哈希清单。
- `scene_build.py` CLI 同样生成轻量 JS 入口；`--out` 仍是显式制作数据输出，建议保存到工程来源目录。`emit_js()` 仅保留旧的独立模块 API/测试兼容，不作为默认网页交付方式。
- `project.py asset-check` 实际操作浏览器，复用模型导出的元数据，并记录请求；新版独立数据模式只允许一次完整几何请求，不允许加载根目录或 engineering 中的完整 `scene.json`。
- `project.py exchange` 从校验过的压缩数据读取原始 payload，继续输出原生 GLB；另附无损 `.glb.gz` 和运输哈希。原生 GLB供消费端/Blender真实导入，不能用 gzip 文件冒充可直接导入的 GLB。
- `project.py export` 仍按同版本哈希、资产功能、交换和已有视觉审查交付。打包大小报告不替代采用质量阀、功能检查或案例接入。

## 旧项目迁移

```sh
python3 scripts/lightweight_delivery.py migrate --source OLD_BUNDLE --out NEW_BUNDLE
python3 scripts/lightweight_delivery.py check --bundle NEW_BUNDLE
```

只接受哈希完整、已知生成格式的 native generic-review 包，输出必须是独立新目录。保留原运行函数、稳定 ID、材质、动作及原来源；仅抽离数据和调整元数据读取。未知外部适配器、锁定车辆旧包、手写 GLB 页面不能猜测改写，须显式接入并做浏览器回归；已有有效旧包仍能通过旧 payload 读取接口消费，不自动追认轻量检查通过。

## 验证与失败处理

- 压缩后解压字节须与本次规范化源字节一致；运输、解压数据、运行模块、元数据、贴图和 bundle 分别记录哈希。源 JSON 规范化不表示浮点量化；旧项目还须核对实际运行的 BufferAttribute 与索引。
- 核对顶点、法线、UV、索引、部件层级、枢轴和材质/纹理参数。用固定机位、灯光、画幅进行多视图对照；确定性环境可要求像素一致，跨设备不能机械要求像素为零。
- 根据对象的真实能力检查换色及保护区域、变体、动作、旋转缩放、场景、保存/恢复、重置和版本切换；不增加原模型没有的交互。
- 哈希错误、损坏数据、缺资源、不支持解压或缺少安全上下文时明确失败，不展示半成品。通用查看器显示错误，锁定模板保持原错误处理契约。
- 当前加载器使用浏览器原生 DecompressionStream、Web Crypto、安全上下文（HTTPS/localhost），不自动安装服务或依赖。压缩文件按原字节作为资源提供；若宿主会自动按 HTTP Content-Encoding 解压，须明确对应运输策略，不能重复解压或悄悄放宽哈希。
- 版本采用仍遵循 adoption-review：退步或不确定的候选保留原版。初次迁移至少包含一类车辆和一类非车辆；独立软件样本验证通用代码，不宣称未见参考图的造型还原已通过。

## 已验证与边界

2026-10 的回归包含现有五个大模型版本（超跑两个来源）、独立双筒收纳架软件样本、GLB真实Blender导入及损坏/不支持解压测试。实际结果与报告在任务证据目录中记录，技能不写入案例专属坐标、配色或固定压缩比例。
