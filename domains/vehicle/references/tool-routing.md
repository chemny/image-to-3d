# 加工路线与持久化

先按问题和已有资产选择工具，保持统一的造型、保护及交付验收。已有 GLB 默认先在 Three.js／原生 GLB 层检查和处理；工具切换需解决具体能力缺口，不能因为开始了新一轮就重建或重新导出整车。

## 选择路线

| 问题与前提 | 优先路线 | 升级条件或限制 |
|---|---|---|
| 材质、灯光、相机、换色或已有配置变体 | Three.js 的配置及运行时材质 | 精确绑定真实资产；缺少轮毂、门内侧或铰链等结构时需先加工资产 |
| 独立构件改位，可信载体和安装面已存在 | Three.js 几何算法或原生 GLB 脚本 | 检查旧安装区残留、接触、密封件与跟随关系；仅改 transform 不一定足够 |
| 已有网格的局部尺寸、顶点或法线问题，允许域与边界可明确 | 保留拓扑、UV 与材料的原生 GLB／Three.js 属性加工 | 修改算法按当前任务编写；特征保护冲突、多壳歧义或支持不足时重新诊断方法 |
| 复杂车身曲面重建、重拓扑、开口连接、倒角、UV 展开或烘焙 | Blender 或具备相应能力的建模工具 | 保留原件，派生 GLB 重盘点角色与索引；离线渲染仍需网页复核 |
| .blend 输入 | Blender 转换为可用 GLB | 转换后按实际问题重新路由，不默认所有后续步骤都留在 Blender |
| 只有图片且无可信底模 | 先建立有证据的比例/轮廓候选，再选择建模工具或已授权的生成服务 | Three.js 可承载明确的程序化几何，但不自动推断真实车身；复杂连续曲面通常适合建模工具 |

整体几何严重错误时，先改主要结构或换可信基线。换工具本身不算造型改善；同一失败目标的反馈预算和未通过记录随路线继承。

## 区分展示改动和资产改动

- 展示改动保存在配置、材质适配器及运行时依赖中，原 GLB 可保持不变。交付注明效果需要哪些代码；重新打开页面应可复现。灰模诊断使用独立材料副本，不能破坏源材质或把临时诊断材料当正式交付。
- 几何改动若目标是修复模型，应写入新 GLB，并在新页面实际解码该 GLB 后验收；浏览器内存中的顶点调整、PNG 或配置 JSON 不等于已修复模型文件。
- 若任务明确选择运行时几何适配，应交付确定性的脚本/参数和基线哈希，防止重复应用位移；重新加载验证效果。明确记录 GLB 本身仍为基线，不宣称单独 GLB 已修复。

Three.js 的 BufferGeometry 提供顶点、法线、UV 与索引操作；形状校准、布尔、重拓扑及安装关系修复仍需专门算法或工具，当前 Skill 没有通用浏览器造型优化按钮。改属性时处理 GPU 更新标记和相关包围体，变更形状后核对法线、切线及绕向；不能对全车盲目重算法线而抹平锐边。

可用 GLTFExporter 导出标准 glTF/GLB，但当前模板未集成模型导出功能。导出前检查版本与扩展支持，导出后检查材质、贴图、UV、动画、层级、角色及运行时依赖。不能假设自定义 shader 会自动烘焙，或重新导出的节点/primitive 索引与原件一致。

实际进行局部属性加工前读取 [Three.js 局部加工与验收](threejs-geometry-review.md)，明确坐标域、零变形保护、着色器法线与输出重新解码。

## 工具无关的版本与验收

在 repair-plan.md 记录路线及理由、改动落在配置/运行时/派生资产的哪一层，以及脚本/参数/输入/输出身份。沿用 [集中优化](model-optimization.md) 和 [验收门槛](optimization-gates.md)；无需为了获得版本记录而运行 Blender。

原生 GLB 准备和清单用 prepare_model.py / asset_manifest.py；实际 Three.js 页面提供多视角、灰模与原材质证据。这些工具不自动识别语义，也不自动修形。需要 Blender 的诊断或编辑能力时才使用 inspect_model.py / blender_pipeline.py。

拓扑、primitive/顶点身份和节点矩阵不变的属性加工，可用 [feature_guard.py](feature-protection.md)。节点变换、拓扑重建或导出重排索引时，该工具不适用；保留对应映射并采用相应的保护及安装检查，重新绑定和验收，不能沿用旧 lock 作为通过证明。

每条路线都核对实际交付版本、受保护特征、同机位改前/改后和相关视角。局部修复、网页功能、模型完整性与整车形似分别报告；图片信息不足及隐藏结构推断不会因选择 Three.js 或 Blender 而消失。

接口依据：[BufferGeometry](https://threejs.org/docs/pages/BufferGeometry.html)、[GLTFExporter](https://threejs.org/docs/pages/GLTFExporter.html)。执行时核对任务使用的 Three.js 版本，网页 vendor 与外部最新版接口不一定相同。
