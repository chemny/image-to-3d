# 图片输入：造型总览确认关卡

适用于用户上传车辆图片、要求建立三维车模或三维配置器的任务。代理负责视角规划、图片一致性检查和建模技术选择；用户只需确认造型，不要求用户提供专业提示词。已有经用户确认且哈希未变的参考包可复用。

## 默认顺序

原图登记 → 一张多视角造型总览图 → 用户明确确认 → 必要的单张参考图 → 基础三维候选 → Three.js 配置器 → 同视角造型及功能分别验收。

**总览图确认前，不批量生成独立单张参考图，不开始新车模的正式建模或精细化，不以静态图加颜色蒙版替代三维交付。** 用户明确选择图片选配器时可另走图片展示路线；不能因只有图片而擅自降级。已有未确认三维候选保留为暂停的诊断稿，不继续扩大施工。

## 一张图怎么准备

1. 先登记用户原图及哈希，判断同车、配置和角度是否一致。足够清楚的已有视角优先原样排版，不为了整齐重新生成。
2. 代理选择能评审当前目标的最少视角。外观通常包括车头、侧面、车尾、前侧45°、后侧45°；高位侧视有参考时可加入，不把它标成正俯视。左右非对称结构按证据补充，不默认镜像。
3. 缺少视角时，先在一次总览生成中补齐；整车默认一张九视角总览（如3×3），另交一张六组结构特写总览，覆盖与建模用途按 [参考到连续曲面标准路径](reference-to-surface.md)；不在确认前批量生成独立单图。各格有编号，整车完整入画，特写带上邻接面；不以多种车漆、轮毂或灯光混淆造型评审。已有八视角批准包按实际覆盖复用，缺口须明确登记。
4. 各格区分原图、生成参考及推测补图。AI生成总览中的“复现原图”也不是原图像素原件，需如实记录。原图仍是最高来源依据；生成图不得覆盖与原图矛盾的结构。
5. 检查比例、轴位、屋顶/窗线、格栅、灯组、门数、轮毂及可见非对称细节跨格一致。重复轮胎、裁切、车头车尾交换或车型漂移需先纠正再提交。
6. 缺少生成能力时仍可用已有原图组成一张确认板，在缺角格内注明缺少证据；说明能力缺口，不把旧模型渲染当作用户原车补图。是否接受不完整范围由用户确认。

## 用户确认与版本

向用户展示当前总览图，只问一个普通语言问题，例如：“这张图里的车辆造型可以作为建模依据吗？有不对的地方，告诉我编号和位置就行。”

确认必须来自用户针对该版本的明确回复；工具成功、代理自检通过、用户沉默、等待超时及此前笼统的执行授权都不算造型确认。用户明确要求跳过时，记录其指令及未确认风险，不能自行代替用户豁免。

总览图需保存版本、SHA-256、逐格来源、原图关联和未知区域。任务记录 reference-approval.json，最少字段：

```json
{
  "schema_version": 1,
  "board": {"path": "references/approval-board-v1.png", "sha256": "ACTUAL_SHA256", "version": 1},
  "status": "awaiting_review",
  "views": [{"id": "rear-quarter", "origin": "generated_inferred", "source_images": ["input/rear.png", "input/side.png"], "notes": "缺少该角度的原始图片"}],
  "approval": null,
  "next_allowed_stage": "review_board"
}
```

状态：awaiting_review、changes_requested、approved、explicitly_waived。approved记录用户原话、消息或任务证据和其确认的总览哈希；不要伪造身份或确认时间。调整会影响造型的格子时输出新版本、重新确认；批准不自动传递到新哈希。

## 确认之后

优先复用清晰的已有原图。总览分辨率足够且格子无裁切时可提取所需视角；精细单张渲染只为相机/轮廓/部件校准等实际需求生成，不能确认后无条件重新生成全部视角。需要新渲染时同时引用用户原图和已确认总览，固定配置及特征，检查与批准版本一致；显著漂移回到总览确认，不将新图默认为已批准。

建模按multiview.md、image-pipeline.md和统一优化门槛执行。确认图是用户认可的设计目标，不是三维扫描或工程标定，也不证明隐藏结构准确。图像制作成功、用户造型确认和最终模型验收必须分别记录。最终 Three.js 网格需与批准参考逐视角对照，材质、交互、下载和性能另行验证。

## 用户指定最终设计基准

用户明确指定批准的生成总览/细节图作为最终成品基准时，另存目标冻结记录、原批准记录和本次指令，不改写历史。后续按该版本进行 [连续返工](fidelity-loop.md)，原图保留溯源；不得换回原图或上一轮模型降低验收目标。通过结论仅限符合批准参考，不声称生成的隐藏结构是实车事实。
