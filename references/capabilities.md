# 已实现能力与范围

| 环节 | 实现 | 仍需执行代理完成 |
|---|---|---|
| 项目入口 | project.py初始化原图/状态、恢复、构建、拟合、采用、捕获、对比、审查、导出 | 看图和真实评审 |
| 输入分析 | 来源、ROI、特征覆盖、模型绑定与推断检查 | 识别没有登记的图像细节、确认造型 |
| 几何 | 共享控制Bezier网络、旋转体、柱体、球体、box、torus、tube、带UV/法线的显式网格，参数与父变换 | 选择合适表达和填写基于参考的控制网；没有自动照片曲面提取器 |
| 校准 | 透视/正交、实际模型点投影、敏感性/秩诊断、校准参数有界搜索 | 语义一致性、参考冲突与未观测几何判断；不保证全局最优 |
| 修正证据 | 前后版本、真实WebGL灰模/材质/轮廓、开合采样、红蓝差异 | 参考独立蒙版与可信机位、表面/功能视觉判断 |
| 装配 | 同源层级/枢轴、实际发光材质、轮毂变体、闭合拓扑与连接点 | 内饰与遮挡结构的合理建模、采样间穿插判断；非连续碰撞引擎 |
| 专业资产 | part/assembly、材质槽、互斥子树变体、选取/独立换色/拆解/动作复位、贴图哈希 | 按真实物体定义拆分与连接；不是自动装配推理 |
| 交换 | GLB几何/材质/UV/贴图/相机/旋转动作，Blender实际导入核验 | 特殊shader烘焙、CAD/NURBS历史、复杂骨骼和软体不在实现内 |
| 显示 | 通用校对页及buildVehicle适配，车辆复用锁定模板 | 根据批准参考填写真实组件和车款配置，不启用假功能 |
| 协作/恢复 | 文件快照、写入范围、漂移检测、check-all；阶段证据与显式rebase | 宿主调度和独立质量审查 |

原先有限解析曲面与synthetic工具保留为可执行软件样例；新项目使用project/scene_build/reconstruction统一链，不要求外部另写基础相机/构建适配器。特殊未支持的几何可先输出显式mesh，仍受同样检查。

尚未证明：新车型/非车辆最终还原质量、相比img2threejs的速度成本优势、任意对象成功率、未测设备性能。这些属于随后用户原图上的成效测试，不是已经自动通过的结论。

方法借鉴本地img2threejs 2.0.0的分析/Spec/阶段执行理念及本地vehicle-configurator经验。新增代码独立编写；Three.js保持随附MIT许可；未复制Apache上游源代码或建立forge依赖。未来复制实际上游代码须保留许可、归属与修改说明。


## 制作标准 v1 扩展

参见 [通用制作标准](production-standard.md)：新增生产契约、真实表面绑定、采样距离/镜像检查、捕获绑定的局部多视角记录以及显式修复审查。新项目在 Spec 阶段强制完整契约；旧项目保持兼容但不追认。规则完整性与视觉还原质量分别验收，未见对象效果需另做独立测试。

## 参考标准 v1

新项目参考准备由reference_set检查并接入workflow阶段：覆盖、实际尺寸/hash、生成设计确认记录和Spec组件/观测归属。参考计划参与引用指纹，修改后不能复用旧确认。旧项目legacy不追认。

anchor_evidence输出网格、真实几何投影偏移、逐特征容差和保护特征回归；不做自动相机求解、语义分割或隐藏结构恢复。仅支持identity图像坐标，裁切/缩放输入明确拒绝而非静默适配。轮廓点仅人工检查，不伪装固定三维点。图像一致性、厚度和全表面衔接仍需视觉审查。开发样本测试记录留在任务，不作为通用成功率声明。

## 局部构造编译（0.6本地）

form_construction提供平行截面loft和星形thick_outline，输出可重建显式mesh；construction_plan将参数链接、参考ROI、实际几何、保护组件和局部多机位检查绑定，workflow按声明检查。它不是自动逆向建模、自由曲面CAD或分叉SDF系统，闭合/数值通过不代表视觉还原。已有资产无需强制改写；形体改造开发试验及未验证能力须单独报告。
