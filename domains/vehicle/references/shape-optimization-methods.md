# 造型优化方法与适用条件

本目录是历史工作中提炼的方法选择规则，供集中优化计划引用；不是自动优化器。当前相机、截面和投射辅助脚本已有实现，鲁棒曲面拟合、共享轮廓施工与特征恢复仍需针对当前资产编写/适配并实测脚本。

| 方法 ID | 适用问题 | 输入与执行约束 | 验证与常见错误 |
|---|---|---|---|
| silhouette-controls | 整体比例、屋顶/窗线、前后悬或轮拱明显错误 | 使用配置一致的参考、已核对相机和可信尺寸/比例；标定主要曲线、轴位和控制截面，只对错误区域修改。图片无底模时先构建这些结构，loft_sections.py 只负责显式截面连面 | 多视角轮廓与独立部件点复核；不能只拟合轮胎、把稀疏猜测截面当原车，或用光顺修错比例 |
| bounded-surface-fit | 基础形状合理，但面板有皱褶或局部不连续 | 空间均衡采样，局部坐标归一化，法线方向/距离筛选邻域，鲁棒拟合排除内壳和离群点；保护真实折线与特征，约束位移和过渡带。样本应来自可信几何/已验证区域，不能把错误基线当真值 | 比较局部形态、轮廓、受保护区域与接合；采样残差/小位移只表示拟合或修改范围，不证明原车准确 |
| uv-safe-sampling | UV 接缝重复顶点或新旧网格密度差导致曲面拟合偏置 | 在位置域建立共同拟合采样并做空间权重平衡，将一致几何位移映回原顶点；保留每个 UV 实例、面成员和材料槽，不直接合并重复顶点 | 核对 UV/面/贴图与接缝；仅位置重合不代表所有法线或材料可合并，尖锐边界需分组 |
| shared-contour-surface | 玻璃、密封边、窗框漂移或各自穿插 | 从同一经核对轮廓与载体表面派生各区域；需要平滑闭合边界时采用共享切线曲线（如分段 Hermite），显式保留设计尖角。厚度/缝隙按任务确定，替换旧面需同步隔离/裁除 | 检查整圈与邻接面，不能只看几个锚点；不直接照搬某车轮廓或独立管条，不以增大补片偏移掩盖源面重叠 |
| feature-preserving-panels | 大面修复削弱门把手、镜座、灯腔或窄饰条 | 先登记特征与跟随关系，从拟合样本排除特征域；保留原件位置/比例，必要时独立构件并在可靠安装面上恢复。协调移动要记录允许变换和材料角色；按 [特征保护](feature-protection.md) 冻结缝线/折线及安装关系，独立构件优先在不变载体上重新安装 | 核对特征轮廓、存在性、相对位置和换色归属；不能将真实凸凹当噪声抹去，不能为保护而锁在错误世界位置 |
| seam-and-normal-repair | 新旧面接合尖刺、皱褶、反光断层 | 先修真实几何边界和重叠，再构造有范围的连续过渡；核对三角绕向与外表面法线。拟合曲面可用解析导数生成一致法线，保留真实锐边 | 灰模与原材质同机位查看；几何仍错时不能靠 shader 法线假装修形，不能全车平滑或盲目填凹形/多环边界 |
| evaluated-surface-patch | 已可用载体上的局部明确补片 | surface_patch.py 可将任务明确、适合中心辐射的区域投射到评估后网格；射线方向、边界、偏移和采样按当前资产设置。它不替代共享结构设计，不自动提供 UV/厚度 | 检查采样点和面内部、边缘、法线及多角度显示；射线命中不保证无穿插，残余痕迹须保留未通过结论 |
| preserve-material-semantics | 材质错分、共享材质串色、导出外观变化 | 保留正确源定义、贴图和 UV，按结构角色局部修复；必要时克隆目标材质实例、分件或明确局部适配器。几何导出变化后检查新索引及运行时依赖 | 实际网页换色与固定部件保护、原材质对照；不能为展示方便清空整车材质，也不能用材质掩盖 B/C 造型问题 |

方法组合由问题决定。基础轮廓合理时无需重新做 silhouette-controls；只改材料时可跳过几何加工；轮廓失败时不能先投入大面抛光。共用曲面和特征保护贯穿相关方法，不是最后补做。

## 方法复诊与转路由

先区分误差来源，再选施工；每个方法在任务记录支持域、必要输入、尺度化参数、保护边界和停止条件。

| 观察到的问题 | 先核查 | 适用动作 / 不适用时转向 |
|---|---|---|
| 同视图多个区域一起偏移/缩放，别的视图不支持该变形 | 机位、裁切、透视、配置 | 校准参考/相机；不直接拉整个车体追图 |
| 同一结构在相关视角持续偏离 | 主要曲线、比例、特征对应 | silhouette-controls；用归一化控制场协调载体与部件。若需大位移才能勉强吻合，复查基线，不无限扩大边界 |
| 比例正确但面板皱褶 | 可信样本、法线筛选、真实折线/小特征 | bounded-surface-fit + uv-safe-sampling；先代表区域试修。支持不足或残差异常时缩域/换基线，不提高拟合阶数追噪声 |
| 玻璃/密封边/框漂移，补片反复穿插 | 共同轮廓、载体和未裁除旧面 | shared-contour-surface；载体本身错误时先回到主体/分区。射线投射不替代旧面替换及边界设计 |
| 把手等存在却位置或比例不对 | 原参考与载体关系，是否只做了存在性保护 | 局部特征定位/重建或协调载体；需要改位时重新登记保护允许变换，不能沿错误位置继续锁定 |
| 灰模正常而原材质异常 | UV、共享实例、运行时角色/语义坐标 | preserve-material-semantics；原材质坐标分类依赖随几何变化适配。新增属性/代码需计入体积、依赖与浏览器验证 |
| 灰模仍尖刺或结构断层 | 面内部、边界、绕向及自交 | seam-and-normal-repair；只有反光改善不算几何修复，实际错误边界先重建 |

融合网格先定义顶点/面域；语义不可靠时不要自动“全车分件”。局部控制场需检查位移、Jacobian、面积/法线及邻接视觉；这些检查各有作用域，均不等于真实形似。按 [加工路线](tool-routing.md) 优先在 Three.js／原生 GLB 层处理已有资产；复杂曲面、拓扑或 UV 操作再使用 Blender 等工具。各路线保存输入、脚本/参数、输出身份与实际评审，不把 Blender 或 Three.js 重导出的版本默认视为无损。
