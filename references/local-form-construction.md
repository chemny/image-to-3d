# 局部形体：从图像观察到可检查的几何

在部件有明显厚度、分叉、收窄、凹槽、层叠或软体压缩时读取。适用于布偶、服装、把手、坐垫、车身开口等局部；简单平板或规则零件不必增加无意义分件。以原图为造型依据，其他实现只提供几何表达方法，不能代替原图。

## 建模前记录形体关系

对影响识别的区域，在项目的施工计划中记录：

- 原图 ID/ROI，能看到的轮廓、材料边界、遮挡；哪些深度仅由阴影推测。
- 对应 component IDs；鼓起、收窄、凹入、厚度、截面变化、相邻体之间的关系。
- 几何表达与理由；可调参数、边界条件、保护机位和不应变化的部件。
- 验收图：原机位与至少一个揭示深度的侧/斜机位；需要时加截面或局部俯视。背面只有推断证据时只评价结构合理性。

这是施工说明，不是新的自动识图 schema。将计划文件加入 Spec.source_files 的路径/哈希以绑定版本，将可见特征登记到 analysis.feature_inventory，真实测量点仍按 integration-contract-v2 绑定几何。不可把文字描述或手填深度当作已恢复的真实三维数据。

## 按局部形状选择表达

| 形体关系 | 可选方法 | 需要保留的结构 |
|---|---|---|
| 沿轴逐渐收窄后鼓起 | 截面放样，或可控变形网格 | 收窄段与体积峰值、截面朝向、连接切向 |
| 多个软体体量融合/分叉 | 体积融合（可用 SDF）或具有相同分支结构的显式网格 | 每个分支的前后深度、鞍面、真实开口与过渡 |
| 片状叠层、发片、衣片 | 带厚度曲面/壳体，按独立造型分片 | 边缘厚度、搭接、贴合间距；不能悬成硬板 |
| 凹槽、开口、包裹关系 | 局部曲面网络或切削后重建过渡 | 槽底/开口边缘的真实位置及深度；避免重叠遮挡片 |
| 刺绣、划线、微小织纹 | 曲面附着几何或合适的纹理 | 附着于已有形体；不代替大尺度收缩、分叉或厚度 |

当前 core 可消费显式 mesh、Bezier 网络及已支持的基本体；新增确定性截面放样与星形厚片编译器见 [形体构造](form-construction.md)，输出仍为显式mesh，不是新增SDF或任意曲面求解器。若使用外部体积/放样构建器，记录实现、版本、采样精度并生成可重建的 mesh，再经现有 Spec→Three/GLB 管线。未知 geometry.type 仍应拒绝。不要为局部任务默认安装新的 DCC 或运行依赖。

不要把所有柔软部件都合成一个椭球后画一圈缝线。也不要为了“有层次”把所有区域拆成互相穿插的小球。是否分件由真实造型、编辑需求和装配决定；相邻分件可共享边界，独立 ID 不要求渲染出缝隙。

## 首个灰模检查什么

先检查截面和局部体积，再增加纹理细节：

1. 固定相机、尺度、光照和材质，保留旧/新局部图以及原图；一次改变一种形体假设。
2. 正面轮廓正确时仍查看侧面和斜面：凹部是否有深度，分支是否前后都成立，厚片是否贴合，收窄处是否仍是一个长球。
3. 对共享边界检查点位、切向/法线；对有设计间隙的零件检查间隙。接点距离为零不等于整圈接缝连续。分段公式在 min/max、截断或融合区边界处也要检查导数，避免新增横向高光带或侧面折点；不要用加环、遮挡片掩盖连接缺陷。
4. 语义拆分后实际检查选择、局部换色、拆解及复位。子件应随所属体移动，不能独立漂走或恢复错位。
5. 保留邻近轮廓与未改部件的回归证据。整体 IoU 只能说明外轮廓，不能代替局部结构与材料界线。

截图/灰模替换材质时排除原来不可见的 helper 与全透明辅助网格，边界归一化使用同一可见范围；不要误把辅助盒算成模型。混合材质的网格应按可见材质组处理，不能因为其中一组透明就丢掉整个网格。修正评估器后保留旧证据并重新捕获所有比较方。

## 接入现有阶段检查

把本任务的重要区域各自登记成 Spec.checks 的 body 阶段必需视觉项，例如：

```json
{"id":"local-branch-volume","kind":"visual","required":true,"stage":"body"}
```

ID 随任务命名，不固定为汽车/布偶。每项 review evidence 单独引用当前几何身份的局部灰模、原图和保护机位；已有 workflow 会拒绝缺项、旧哈希或 method 为数值指标的视觉通过记录。它只验证记录完整性，不能判断图像是否真的达标。

缺失的关键局部不能用邻近点替代，不把删去缺失点后的 RMS 当完整验收。作者开发自评与独立复查分开：因局部问题重建时，由独立复查确认该问题及周边回归；不在证据不足时把作者自评写成独立通过。宿主无法独立审查时明确标注作者自评，不伪装第二个评审者。

局部改善和整体成品验收分别给结论。已用于选方法的对象属于开发回归；一个软体实例的改善不证明车身、任意玩具或全部单图任务都更快、更准确。

## 修复工具接入

已有模型局部施工按 [通用修复流程](repair-workflow.md) 声明保护与附着关系。surface_attachment提供声明的表面采样距离、开口阻挡射线及有限的凸投影切口工具；必须补实际回边并多角度审查，工具不覆盖未采样面。
