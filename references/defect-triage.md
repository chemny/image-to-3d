# 缺陷分诊：先验证原因，再选择施工方法

用于已有模型的检查和修复准备。沿用任务问题清单、repair_contract 和采用审查，不增加审批状态或另一套评分。模型身份先按 presentation-delivery.md 核实；本页只补原因判断，不重复参考准入和施工流程。

## 检查顺序

1. 在当前实际模型和参考对应区域定位缺陷，记录部件、参考 ROI、受影响接口和保护内容。机位未校准时只描述可见差异，不给精确比例结论。
2. 固定几何/相机，切换中性材质、轮廓、原材质和诊断光，按需选择。中性仍是有光照的渲染，不是几何真值；蒙版、实际截面和三角面测量用于交叉核实。掠射光和条纹用于暴露问题，不能把照片高光描成凹凸。
3. 用下表选择现有工具验证假设。现象可能有多个原因，不因“像掉漆”就只改颜色，不因“有折痕”就全局平滑。证据不足记录未确定，先做能区分原因的小检查，不直接覆盖模型。
4. 只把已确认的原因和对应修复范围写入原问题条目；区分测量事实、视觉观察、推断及未测项。采用和回退复用已有质量阀。

## 原因与工程入口

| 现象 / 候选原因 | 最小区分证据 | 复用工程能力与修复方向 |
|---|---|---|
| 比例/轮廓偏差，可能是机位或几何 | 固定锚点和原图机位；再看深度角度 | anchor-calibration、coarse-initialization；先定位机位与体量，不盲目整体缩放 |
| 孔洞、毛刺、裂缝、碎面 | 实际拓扑边、退化三角形、接缝间隙和背面观察 | mesh_checks、surface_quality；重建受损边界或补面，保留设计开口，不用加粗饰条遮缝 |
| 平面/曲面起伏或褶皱 | 实际截面折转与曲率变化；固定条件下掠射光对照 | 连续曲面施工；固定边界及设计线，选择已有 loft/blend/patch，检查曲率方向变化 |
| 光滑几何却出现异常亮斑 | 真实三角面法线与着色法线、绕序和材质切换对照 | mesh_checks、repair normal 约束；修正绕序/法线或材质问题，不能只通过抹平着色隐藏真实折痕 |
| 斑块/闪烁，可能是重叠面或深度冲突 | 查相近重叠层；诊断副本逐层隔离，固定相机复现 | 结合原网格及层级检查移除重复来源；当前工具没有通用自动重叠面求解器，不用颜色覆盖代替排查 |
| 部件悬空、穿入、接缝不均 | 实际安装根部的表面距离、法线侧、接口周边及深度视角 | surface_attachment 根部 anchors、限定 host_faces、distance/normal 约束；先修宿主再重算附件落点 |
| 底色、漆面、毛绒或微纹理不对 | 固定光照/曝光，分别替换材质与照明；观察尺度和纹理方向 | systematic-production 的表面分支；纹理、粗糙度及照明分别调整，不无依据改几何 |

这里的原因分类由执行代理根据证据完成，不是自动图像缺陷识别器。拓扑无错误不排除重叠面、错误造型或材质问题；最近距离通过不证明整件装配正确；条纹好看不证明全局 G2。

## 相应回归的含义

`test_engineering_regression.py` 用合成网格注入根部单点悬空、过度埋入、错误宿主面及等幅曲率反转，验证工具是否输出对应数值失败；并穿过真实 repair/build 入口检查约束生效。既有 surface_quality、mesh_checks、local_deformation_guard 测试覆盖裂缝、绕序、假平滑法线和二元变形折痕。它们验证原因区分所依赖的工程测量，不证明代理能从任意图片自动正确分诊。材质/灯光及重叠面的视觉诊断仍需实际观察，不以软件测试冒充已验证。
