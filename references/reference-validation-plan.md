# 参考到模型的分层测试

## 自动工具测试

正例及负例分开：缺关键视角/局部覆盖、生成图未确认、图片尺寸或哈希不符、计划变化后旧审批、移除新项目策略、遗留项目兼容。标定工具测试实际几何投影的已知位移、未知绑定、相机/尺寸错配及旧标注身份。已有红蓝工具继续测试红=多出、蓝=缺少且不自动扭曲对齐。

## 故障注入与视觉责任

移动部件应产生对应方向锚点偏差；缩短特征应导致局部轮廓缺失；压薄体积需侧面/另一方向观察；断开根部须连接检查及视觉复核；修目标部位同时检查保护部位。未实现自动厚度/全表面碰撞检查时明确依赖人工审查，禁止声称全自动拦截。

## 完整案例

开发案例：小鸡，记录补图和确认时间、首版耗时、返工、关键缺陷。已知回归：车辆或布娃娃，冻结原始资产，仅隔离测试。独立样本：未参与规则调试的对象，原始材料另行取得；不得用熟悉小鸡宣称泛化。

同交付目标、同相机/参考、相近资源预算比较，记录总时间包括补图；旧记录不完整不计算精确加速百分比。视觉与工程结果分别报告，无总分抵消关键局部失败。不同任务容差由图像分辨率、标注不确定度和用途在拟合前定义，不在失败后放宽。

## 修复记录

每轮记录：区域、原因(camera/proportion/representation/connection/normals/material/runtime)、修改范围、预期效果、保护特征、前后模型与参考身份、固定机位证据、结果。连续两轮无显著改善重新审查表达和对应关系，不盲目细分。

已实现脚本测试不等于完成真实图像到成品测试。报告分别列软件验证、开发案例、历史回归、独立样本状态及等待的用户决定。
